LINKEDIN PROJECT LAUNCH POST

I recently completed SentinelTrace, a Python-based SSH authentication log monitoring and threat detection lab.

The problem I wanted to explore was simple: manually reviewing authentication logs can make it harder to spot repeated login failures and suspicious account access quickly.

SentinelTrace parses Linux OpenSSH authentication logs and applies three rule-based detections:
• Repeated SSH authentication failures within a defined time window
• Successful authentication after a repeated-failure burst
• Remote SSH login to the root account

It prioritizes alerts and generates JSON, CSV, and HTML reports to support first-level SOC investigation and documentation. It also includes an optional file-follow mode for new entries in an authorized local log file.

In the included controlled test scenario, the tool analyzed 8 synthetic events and generated 3 alerts: 1 Critical and 2 High. All 5 unit tests passed.

This is a portfolio lab using synthetic data, not a production SIEM deployment. My next improvement areas are Windows event-log parsing, configurable detection rules, and SIEM integration in a separate lab environment.
