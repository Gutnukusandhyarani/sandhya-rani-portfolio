PROJECT 1
Name: SentinelOps | Hosted Endpoint Monitoring & SIEM Lab
Associated with: Independent Portfolio Project

Description:
Built a Python-based endpoint monitoring and SIEM learning lab with an authorized Windows System event collector, event normalization, rule-based detections and persistent Supabase storage. Deployed the hosted API and aggregate-only public dashboard on Vercel, with a separate analyst console for reviewing event records and managing alert triage.

Highlights:
• Implemented a read-only Windows collector for selected System event IDs and bounded HTTPS ingestion batches.
• Added server-side collector credential validation, retry-safe record handling and database-backed event/alert persistence.
• Built detection and alert workflows, plus a public dashboard that exposes aggregate metrics rather than sensitive endpoint identifiers.
• Implemented a private analyst console with alert evidence, searchable event records, status updates and analyst notes.

Scope note:
At the 23 November 2026 verification checkpoint, the hosted dashboard reported 153 stored endpoint event records and one high-severity service-installation alert. A service-installation alert is a review prompt, not proof of malicious activity. Successful browser login, persisted triage and scheduled collector startup still require end-to-end verification. This is a defensive portfolio lab, not a production SIEM.

PROJECT 2
Name: SigmaForge | Detection-as-Code Workbench
Associated with: Independent Portfolio Project
Repository: https://github.com/Gutnukusandhyarani/SigmaForge
Dashboard: https://sigma-forge-mu.vercel.app/

Description:
Developed and deployed a read-only detection-engineering workbench for validating YAML rules, evaluating supported detection conditions against regression fixtures, mapping ATT&CK techniques and compiling supported rules into Splunk SPL, Microsoft Sentinel KQL and Elastic query syntax.

Highlights:
• Implemented YAML schema, UUID, selector and condition validation with rule-quality warnings.
• Built positive/negative fixture testing and ATT&CK coverage reporting.
• Added SIEM query generation for three backends and SentinelOps-compatible rule-pack export.
• Hosted the public rule explorer and API on Vercel.

Verified checkpoint:
The deployed API reported 6 rules, 6 valid rules and 8/8 passing regression cases on 23 November 2026. These results apply to repository fixtures, not live endpoint telemetry. Generated queries must be validated in the destination SIEM.
